<objective>
Fix the wrong host traversal pattern used in create_vm, create_vm_custom, deploy_ovf, and deploy_ova.

Purpose: The current code uses `self.content.rootFolder.childEntity[0].host[0]` which fails because `childEntity[0]` is a `vim.Datacenter` — it has no `.host` attribute. This raises AttributeError at runtime. Additionally `vm_folder = host_system.vm` returns a `VirtualMachine[]` list, not a `vim.Folder`, so `CreateVM_Task` and `ImportVApp` raise `NotSupported`. All four methods need the same two-line fix.

Output: vmware_manager.py with self.compute_resource stored in _connect_vcenter and all four call sites corrected to use `self.compute_resource.host[0]` and `self.datacenter_obj.vmFolder`.
</objective>
